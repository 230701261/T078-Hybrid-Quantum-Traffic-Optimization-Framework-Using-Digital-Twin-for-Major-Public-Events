## Hardcode dispositions

- Chepauk location, real network geometry, SUMO route definitions, corridor/junction mappings, and the 18-variable decision schema remain intentionally static configuration.
- Remove sample-seeded live scenario metrics and static status defaults.
- Keep optimizer-derived benefits only as explicitly labeled model estimates; measured telemetry must be a separate data object and display.
- Supabase is **BLOCKED EXTERNAL DEPENDENCY** if credentials or network access are absent; never report cloud success from local fallback.
